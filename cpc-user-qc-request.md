# cpc-user-qc-request

Opens the Quality Card Request SharePoint list and the local QC cards folder for a CPC user.

## Overview

Convenience launcher for CPC users: opens the Quality Card Request SharePoint list in the default browser, then opens the local `C:\CPCQCards` folder in File Explorer if it exists. Windows-only.

## Usage

```powershell
uv run main.py
```
